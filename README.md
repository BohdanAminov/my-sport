# MY SPORT — тренувальний щоденник

Безкоштовний мобільний вебзастосунок (PWA) українською мовою без сервера, входу та реклами.

## Що вже є
- Твій спліт: понеділок — плечі/руки; середа — груди/спина; п'ятниця — ноги.
- Початкова бібліотека з 40+ вправ, які згадувалися у твоєму журналі.
- Додавання та перейменування своїх вправ. Можна додати вправу в день спліту, міняти порядок, прибирати з плану.
- Введення робочої ваги, повторів, розминки, нотаток, дати. Підходи позначаються як завершені.
- Збереження незавершеної чернетки й копіювання минулих підходів.
- Історія, рекорди, прогрес, підрахунок умовного обсягу, таймер відпочинку.
- Повний експорт/імпорт журналу JSON та експорт підходів CSV.
- Робота офлайн **після першого завантаження з HTTPS**.

## Що перенесено з минулих записів
- Стартовий набір вправ за підтвердженим переліком у чаті.
- Окремі підтверджені рекорди, зокрема жим 90×7 (21.10.2026).
- Часткове підтверджене тренування ніг 16.10.2026 (5 вправ × 3 підходи).
- Повна історія старого чату **не була доступна**, тому інші тренування не вигадані.
- Рекорди, для яких не відома точна дата, позначено без дати в початкових даних.

## Запуск прямо зараз на комп'ютері
1. Розпакуй ZIP в окрему папку.
2. Відкрий `index.html` у браузері. Застосунок працюватиме як локальна сторінка. 
3. Для повноцінного встановлення PWA на телефон потрібен HTTPS.

## Найпростіша безкоштовна публікація через GitHub Pages
1. Створи **публічний** GitHub-репозиторій, наприклад `my-sport`.
2. Завантаж у корінь репозиторію вміст папки `MY_SPORT`: `index.html`, `app.js`, `style.css`, `sw.js`, `manifest.webmanifest`, папку `icons`.
3. У репозиторії відкрий **Settings → Pages**.
4. Обери **Deploy from a branch**, гілку `main`, каталог `/ (root)` і збережи.
5. Коли GitHub Pages покаже вебадресу, відкрий її на телефоні.
6. На iPhone у Safari обери **Поділитися → На початковий екран**. На Android у Chrome — **Установити застосунок** або **Додати на головний екран**.
7. Після відкриття значка дані ведуться локально саме на цьому телефоні. Ніяких акаунтів не потрібно.

**Зверни увагу:** публічний репозиторій містить тільки код і **стартовий набір загальних вправ/відомих рекордів**, але не твої наступні локальні записи. **Ніколи не завантажуй особистий файл `MY_SPORT_backup_*.json` у публічний репозиторій**.

## Резервне копіювання
Зайди до **Налаштування → Завантажити весь журнал (JSON)**, збережи файл у «Файли»/хмарному сховищі, яке контролюєш. На іншому телефоні обери **Відновити з копії JSON**. Імпорт повністю замінює поточну базу.

## Важливі обмеження
- Програма не синхронізує дані між пристроями автоматично.
- Очищення даних вебсайту або зміна пристрою без JSON-копії може стерти журнал.
- Рекорди тренажерів різних залів умовно порівнювані: їхні передавальні механізми можуть відрізнятися.
- Тоннаж — вага, внесена у поле, помножена на повторення. Для гантелей це вага **однієї** гантелі, для вправ з масою тіла власна вага не врахована.
- Таймер на заблокованому екрані може не подавати звукових повідомлень.
- Це локальна перша версія без хмари, доступу до Apple Health і бази харчування.

## Як редагувати застосунок далі в Codex
Відкрий цю папку/репозиторій у Codex і пиши нові завдання. Усі дані зберігаються в `localStorage` за ключем `MY_SPORT_V1`. Зберігай сумісність формату та не замінюй існуючі дані під час оновлень. Після редагування `app.js`, `style.css` або `index.html` онови версію кешу в `sw.js`, щоб встановлена PWA отримала нові файли.
